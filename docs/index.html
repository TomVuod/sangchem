Introduction

This book presents analytical workflows taking the raw data and processing them up to the final results reported in the manuscript. The dedicated functions and data sets were compiled into sangchem R package which is available on GitHub and can be installed using the following command:

if(!require(devtools)) install.packages("devtools")
devtools::install_github("TomVuod/sangchem")
