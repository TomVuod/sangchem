This is the R package containing the code used to process the data supporting the following [publication]([https://link.springer.com/article/10.1007/s00265-026-03738-0?utm_source=rct_congratemailt&utm_medium=email&utm_campaign=oa_20260519&utm_content=10.1007/s00265-026-03738-0]):

Włodarczyk, T., Schmitt, T. Coming out from the shadows: facultative slave-making ants reveal their chemical identity during colony development. Behav Ecol Sociobiol 80, 71 (2026). https://doi.org/10.1007/s00265-026-03738-0


## Usage
Installation
```
if(!require(devtools)) install.packages("devtools")
devtools::install_github("TomVuod/sangchem")
```
Loading
```
library(sangchem)
```
Generating supplementary materials (by default in the current working directory)
```
render_supp_materials()
```

## Additional data
The raw GC/MS data generated as a part of the study has been deposited at [MetaboLights](https://www.ebi.ac.uk/metabolights/):  [https://www.ebi.ac.uk/metabolights/MTBLS13712](https://www.ebi.ac.uk/metabolights/MTBLS13712)
